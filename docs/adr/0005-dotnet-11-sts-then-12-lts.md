# .NET 11 (STS) now, .NET 12 (LTS) next

Navpaky targets .NET 11, a Standard Term Support release, not .NET 10 LTS. .NET 11 is supported until 2028-11-14, the same day .NET 10 LTS ends, so moving costs no support time and gives the design overhaul C# 15, the current WPF and the SDK the repository already pins. The app ships self-contained, so users never install a runtime and the support class only decides how long Microsoft patches the runtime inside our package; Dependabot and Velopack updates bring those patches. The cost is a forced move: .NET 12 LTS is due in November 2027, and Navpaky moves to it within six months, well before .NET 11 ends. The target framework is one property, `DotNetTargetFramework` in `Directory.Build.props`, and `global.json` pins the SDK, so that move is two lines plus whatever the .NET 12 breaking-change list asks for. Considered: staying on .NET 10 LTS until .NET 12 (no gain in support, and the overhaul would be built on an older WPF and then moved).
